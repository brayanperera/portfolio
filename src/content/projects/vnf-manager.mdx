## Architecture

<Diagram name="vnf-manager" />

The platform is made up of eight microservices. I built two of them. The VNF Package Parser reads VNF packages, and the VIM Adapter talks to OpenStack through Terraform. Around those I built a TOSCA VNF Package Creator tool and the Ansible automation framework.

## My role

I was principal architect, responsible for the OpenStack integration and for the microservice API and workflow design.
